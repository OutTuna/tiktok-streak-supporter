# TikTok Streak Keeper

Десктопное приложение на [Flet](https://flet.dev) для автоматической отправки сообщений выбранным собеседникам в TikTok — например, чтобы не терять стрик в переписке. Приложение сворачивается в трей и в заданное время отправляет сообщение через Playwright.

## Возможности

- Авторизация в TikTok через встроенный Chrome-профиль (сессия сохраняется локально)
- Список последних диалогов с чекбоксами для выбора получателей
- Настраиваемый текст сообщения и время отправки (HH:MM)
- Сворачивание в системный трей с иконкой и меню («Развернуть» / «Выход»)
- Автоматическая отправка сообщений по расписанию через `schedule`
- Опция автозакрытия программы после отправки
- Журнал отправок (`nudge_log.txt`) с историей успехов и ошибок

## Стек

- **flet** — UI
- **playwright** — управление браузером Chrome
- **schedule** — планировщик задач
- **pystray**, **pillow** — иконка в трее

## Установка

1. Убедитесь, что установлен Python 3.9+.
2. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

   > В репозитории файл называется `requierements.txt` (опечатка) — либо переименуйте его в `requirements.txt`, либо укажите это имя явно:
   > ```bash
   > pip install -r requierements.txt
   > ```

3. Установите браузер для Playwright:

   ```bash
   playwright install chrome
   ```

## Запуск

```bash
python main.py
```

При первом запуске откроется окно Chrome для входа в аккаунт TikTok — сессия сохранится в папке `tiktok_session/` и повторной авторизации не потребуется.

## Использование

1. Дождитесь загрузки списка диалогов.
2. Отметьте пользователей, которым нужно отправить сообщение.
3. Укажите текст сообщения и время отправки (формат `ЧЧ:ММ`).
4. При необходимости включите/выключите автозакрытие после отправки.
5. Нажмите «Свернуть в трей и ждать» — приложение уйдёт в трей и будет ждать указанного времени.
6. В заданное время сообщения отправятся автоматически; результат появится в `nudge_log.txt` и в истории отправок при следующем разворачивании окна.

## Структура проекта

```
.
├── main.py            # UI на Flet, точка входа
├── tiktok.py           # Логика работы с TikTok через Playwright
├── tray_scheduler.py   # Трей-иконка и планировщик отправки
├── requierements.txt   # Зависимости (опечатка в имени файла)
└── nudge_log.txt        # Создаётся автоматически — журнал отправок
```

## Важно

- Автоматизация действий в TikTok через Playwright может нарушать условия использования сервиса и привести к ограничениям на аккаунте — используйте на свой риск.
- Сессия браузера (`tiktok_session/`) содержит куки авторизации — не публикуйте эту папку и добавьте её в `.gitignore`.
- Селекторы TikTok (`data-e2e="..."`) могут измениться в любой момент — при поломке потребуется обновить `tiktok.py`.
